01. Executive Summary & Objective

The primary objective of this deployment was to engineer a localized, secure server environment to learn core networking, container orchestration, and self-hosted service administration on custom enterprise hardware.

03. Stack Architecture & Deployment

  • Hypervisor Layer: Proxmox VE driving segmented workloads via LXC containers and VMs.
  • Storage & Media: TrueNAS VM managing ZFS arrays, feeding LXCs for Plex and automated media pipeline applications.
  • Containerization: Portainer managing isolated Docker stacks for backend services and VPN gateway routing.
  • Monitoring & Metrics: Uptime Kuma for service availability tracking and latency alerting (Grafana pipeline deployment in progress).

04. Engineering Case Study: Latency & Internal Routing

[ISSUE DETECTED]: High internal network latency spikes and throughput bottlenecks across local Docker service bridges during multi-client streaming.
[ROOT CAUSE]: Sub-optimal routing configurations across Virtual Subnets and unprioritized local traffic queues.
[REMEDIATION]: Reconfigured internal virtual network interfaces within Proxmox, optimized switch VLAN tagging, and streamlined container network bindings.
[OUTCOME]: Achieved steady-state low latency, optimized internal bandwidth distribution, and stabilized cross-service communication across all Docker stacks.
