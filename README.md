## 🖥️ System Architecture & Sub-Pages

This repository contains a modular multi-page system design:

* **`index.html`** — Primary control panel featuring system overview, core IT Management competencies, and project deployments.
* **`cv.html`** — Curriculum Vitae detailing academic standing at SETU Carlow, technical background, and operations history[cite: 2].
* **`ops-report.html`** — HomeLab SecOps operational write-up covering bare-metal Fujitsu rack topology, Proxmox hypervisor, TrueNAS ZFS storage, and network latency remediation.

## 🤖 AI-Assisted Engineering

This portfolio was architected using generative AI collaboration as a thought-partner and rapid prototyping engine. The implementation demonstrates:
1. **Accelerated Delivery:** Rapid generation of semantic HTML5/CSS3 TUI components without pre-built external frameworks.
2. **Design Consistency:** Strict adherence to custom TUI color schemes, typography, and responsive layouts across all sub-pages.
3. **Iterative Refinement:** Prompt-driven refactoring to bridge hands-on technical homelab projects with formal IT Management terminology.
