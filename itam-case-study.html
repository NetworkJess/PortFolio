Automated ITAM & Incident Pipeline // Case Study

[ITIL FRAMEWORK IMPLEMENTATION]

01. Business Case & Objective

As homelab server infrastructures grow, tracking physical hardware lifecycles, virtual storage allocations, and active service licenses quickly becomes unmanageable without enterprise tools.

This project implements an automated **IT Asset Management (ITAM)** and telemetry system. Combining self-hosted software inventory management with real-time uptime monitoring provides full visibility over local rack assets and automates proactive incident alerts.

03. Technical Implementation

  • Asset Cataloging: Deployed a containerized Snipe-IT stack with MySQL backend to log rack hardware, drives (ZFS pool members), switch port maps, and software licenses.
  • Telemetry Integration: Configured Uptime Kuma endpoints to ping critical web services, LXC IP addresses, and NAS shares every 60 seconds.
  • Automated Incident Routing: Linked Uptime Kuma event webhooks to trigger immediate notifications when service thresholds fail.

04. ITIL Service Management Alignment

  • Service Asset & Configuration Management (SACM): Maintains accurate configuration items (CIs) and mappings between physical hardware and hosted LXC/Docker services.
  • Incident Management: Reduces Mean Time to Detect (MTTD) by automating failure alerts prior to end-user impact.
  • Proactive Maintenance: Enables preventative maintenance scheduling for physical server bays and drive replacements based on asset age and health telemetry.
